# Supply Chain Sales Analytics Dashboard 📊

An interactive **Power BI dashboard** developed to analyze supply chain sales, profitability, orders, products, markets, and delivery performance.

## 📊 Key KPIs

| KPI | Value |
|---|---:|
| 💰 Total Sales | **12.34M** |
| 📈 Average Sales | **12.34M** |
| 🧾 Total Orders | **62.65K** |
| 📦 Total Quantity | **138K** |
| 💵 Total Profit | **1.32M** |

## 🔍 Dashboard Analysis

- Analyzed **2 years of sales data** to identify sales trends and patterns.
- Evaluated sales performance across different **product categories**.
- Analyzed **market-wise order distribution** using interactive visualizations.
- Compared **sales and profit by product** to identify high-performing products.
- Analyzed **order delivery status** to understand fulfillment performance.
- Used slicers for **Year, Market, Category, Shipping Mode, and Customer Country**.
- Created interactive KPI cards and charts for quick business performance monitoring.
